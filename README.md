# Sweet Shop Management System

This repository contains a Sweet Shop Management System kata scaffold (backend + frontend).

**Backend**: Node.js + TypeScript + Express + Mongoose (MongoDB)
**Frontend**: React (Vite)

## Quick Start

- Copy `backend/.env.example` to `backend/.env` and set `MONGO_URI` and `JWT_SECRET`.
- Install backend deps and run:

```bash
cd backend
npm install
npm run dev
```

- Install frontend deps and run:

```bash
cd frontend
npm install
npm run dev
```
